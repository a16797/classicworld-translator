ClassicWorld 翻译助手 使用说明
====================

用途：冒险岛 Classic World 专用的聊天翻译助手。把你打的中文翻成玩家常用的英文简写，
自动复制，回游戏按 Ctrl+V 就能发。
例如：废弃都市组队任务来法师三缺一 → R> KPQ mage 3/4
      你好，请问有人能给我加个圣火吗，谢谢 → HB pls ty

一、打开
1. 把压缩包整个解压到任意文件夹（不要直接在压缩包里双击运行）。
2. 双击 CWTranslator.exe。
3. 程序未签名，Windows 可能提示“未知发布者”。先核对 GitHub 发布页的下载来源和 SHA256；
   确认文件可信后再选择运行。
4. 程序会常驻在右下角托盘（橙色 CW 图标），右键可以打开设置或退出。

二、填 DeepSeek Key（第一次打开会提示）
- 常用喊话、词库里有的句子不用 Key，本地直接出结果。
- 没见过的新句子需要联网，用的是 DeepSeek，要一个 API Key：
  1. 点“打开 DeepSeek 申请页”（https://platform.deepseek.com/api_keys），注册登录；
  2. 充值少量金额（聊天用量很小）；
  3. 创建 API Key（sk- 开头），复制，粘贴到小窗里，点“测试”，显示“可用”后点“保存”。
- Key 用 Windows DPAPI 加密保存在 %APPDATA%\CWTranslator\settings.json，不写入明文或安装包。
- 新句子的文本会发给 DeepSeek 翻译，Key 仅通过 HTTPS 发给 DeepSeek 用于认证；本地命中不发翻译请求。
- 设置页显示正在使用“已保存的 Key”还是 DEEPSEEK_API_KEY 环境变量，留空表示不改已保存的 Key。
- 勾选“清除 Key 并停用环境变量”再保存，本程序就不再使用 Key；不删除其他程序共用的环境变量。
- 加密配置无法解密时会提示重新填写。不要把设置文件和聊天缓存一起发给别人。

三、在游戏里用
1. 在游戏里按 Ctrl+Alt+Q，小窗弹出。
2. 打中文，按回车。
3. 结果自动复制，小窗自动隐藏并切回游戏；在聊天框按 Ctrl+V，再回车发送。
- 按 Esc 直接返回游戏；再按一次 Ctrl+Alt+Q 也会收起小窗。
- 同一句话翻过一次，下次直接出，不再联网。
- 快捷键可以在设置里改：点一下快捷键框，直接按想用的组合键。

四、翻得不满意？
- 直接在结果栏里改，改完点“复制”（小窗不会收起），或按回车（复制并回游戏）。
- 改过的译法会自动保存，以后同一句话都用你改好的版本。
- 保存的句子都在“我的喊话表”里（托盘右键 → 打开我的喊话表），可以用 Excel 编辑：
  第一列中文、第二列英文简写。

五、查现成说法
- 在输入框里只打几个字（例如“招人”“圣火”“柠檬”），下面会列出相似的现成说法。
- 所有游戏物品、怪物、地图、NPC、技能的中英名称都能查（例如 柠檬 → Lemon，绿水灵 → Slime）。
- 打“收／卖／换 + 物品名（+数量）”会直接拼好一句，例如 收柠檬100个 → B> Lemon x100。
- 点一条就填好并复制；也可以按 ↓ 选中、回车确认。
- 列表最上面是“推荐”：拼好的整句、你常用的、完全一样的排在前面，接着是整句和黑话单词（你的喊话表排最前）。
  再往下按分类列出物品、怪物、技能、地图、NPC 的中英名称。
- 用 ↑↓ 选择时会自动跳过组标题。

六、常见问题
- 游戏全屏时切换会闪一下：把游戏设成“无边框窗口/窗口化”体验最好。
- 按快捷键没反应：可能被别的软件占用了，到设置里换一个快捷键。
  如果游戏是“以管理员身份运行”，本程序一般也能收到快捷键；若不行，右键 CWTranslator.exe →“以管理员身份运行”。
- 提示 Key 不对 / 余额不足：到 DeepSeek 开放平台检查 Key 或充值。
- 提示联网超时：检查网络；本地有的句子不受影响。
- 程序不会自动往游戏里打字或发消息，发送永远由你自己按。

七、数据位置
- 设置、我的喊话表、翻译记录、使用次数：%APPDATA%\CWTranslator（设置里“打开数据文件夹”）。
- 配置文件是 settings.json；翻译缓存是 cache.json；使用次数是 usage.json，均留在本机。
- 升级新版本：解压新版本覆盖旧文件夹即可，你的设置和喊话表不受影响。
- 卸载：退出程序，删除程序文件夹；如需清除个人数据，再删除上面的数据文件夹。
