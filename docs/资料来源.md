## 这一版收录了多少？

当前聊天词库于 2026-09-30 导出，共 7,326 条名称、词语和样例，包含 1,892 句可以直接使用的中英喊话。网页来源的底层快照是 2026-08-29；不是实时同步游戏更新。

来源记录分别为：名称目录 3,631 条、MSCW 补充 634 条、玩家常用英文 166 条、常用词 817 条、聊天样例 2,078 条。记录可能包含同一名称的不同说法，不等于 7,326 个不同物品。词库另有 25 条整理后的补充词条。

部分样例存在中英不一致：61 条物品错配样例不用于整句直出，另有 7 组答案冲突没有选作直接答案；需要核对的清单保留在 `data/待核对样例.csv`。发现问题可通过 GitHub Issue 提交原句和建议译法。
