# 开发说明

本页供修改源码、测试和打包的人使用。玩家使用说明在 [README](../README.md)。

## 文件分工

| 位置 | 用途 |
| --- | --- |
| `app.py`、`engine.py`、`settings.py`、`winapi.py`、`icon.py` | 界面、翻译流程、本地设置和 Windows 操作 |
| `vendor/` | 随源码发布的翻译核心快照，不依赖开发者的个人 Skill |
| `data/` | 随包聊天词库、默认喊话表和图标；`待核对样例.csv` 供校对 |
| `tests/` | 单元测试、窗口测试和按键测试 |
| `tools/` | 发布前的密钥与个人文件扫描 |
| `docs/` | 来源与开发说明 |
| `build.ps1`、`make_zip.py`、`version_file.py` | 打包、生成 ZIP、写入 exe 版本信息 |
| `prepare_data.py` | 维护者从本机上游 Skill 重新导出数据 |

以下仅用于本地，不提交 Git：`.venv/` 是依赖环境，`build/` 是构建产物，`dist/` 是 ZIP 和解压后的程序，`__pycache__/` 是 Python 缓存，`开发记录.md` 是本地记录。

个人设置位于 `%APPDATA%\CWTranslator`，不放在源码或发布目录中。隐私和安全说明见 [SECURITY](../SECURITY.md)。

## 运行与测试

需要 Windows、Python 3.11 或更新版本、PowerShell 7。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -p 'test_*.py'
.\.venv\Scripts\python.exe tests\smoke_app.py
pwsh -File build.ps1
```

普通打包使用仓库自带词库和 `vendor/` 核心。`pwsh -File build.ps1 -RefreshData` 才从本机 `cw-chat-assistant` Skill 导出新资料；之后审查数据和核心快照，不修改个人数据。

测试默认不调用付费 API。`tests/smoke_app.py --network` 会使用当前环境中的 Key 发出真实请求。真实按键测试 `tests/e2e_focus.py` 会操作前台窗口；先退出已运行的工具，并安排在用户不操作电脑时执行。

## 版本与发布

`app.py` 中的 `APP_VERSION` 是唯一代码版本号来源。每次发布前查询 GitHub 已发布版本，自动递增，避免重号：修复升补丁号，新增功能升次版本号，不兼容改动升主版本号。仅修改文档不另发安装包。

本地 ZIP 为 `dist/ClassicWorld翻译助手-vX.Y.Z.zip`，GitHub 下载名称为 `ClassicWorld-Translator-vX.Y.Z-Windows.zip`。窗口、exe 属性和 Release tag 保持一致。Release 附简要更新说明与 ZIP 的 SHA256。

提交前运行 `python tools/scan_public.py`，打包脚本也扫描输出目录。只发布 `translator` 仓库中的文件，不把上层 ClassicWorld 的完整资料库、客户端和原件一起发布。

## 目录整理原则

代码体量较小，保留现有模块位置，避免为分文件夹而修改导入和打包路径。玩家文档、开发文档和数据出处分开即可。

构建缓存可以重建，旧 ZIP 可以按版本归档；移动或清理前核对精确路径、当前进程和快捷方式。正在使用的程序目录、词库原件、个人配置和完整资料库不能按“重复文件”直接删除。
